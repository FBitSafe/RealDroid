Fix015 — residual NN stepping, compliant landing, and foot-impact penalty
Date: 2026-10-05

0. Reconnaissance

a) Before this change, MotorRom's relevant defaults and state were:

    const float SwingDuration = 0.45f;
    const float SwingHeight = 18f;
    const float SwingStiffness = 0.2f;
    public bool CapturePointStepping = true;
    int _swingFoot = -1;
    float _swingElapsed;
    float _swingStartX, _swingStartY, _swingTargetX;

The complete pre-change ApplyCapturePointStep was:

    void ApplyCapturePointStep(Brain b, float dt)
    {
        var body = b.Body;
        var recover = b.P[Protocol.Recover];
        if (recover < 0.5f || !body.HasSupport)
        {
            _swingFoot = -1;
            _stepArmed = true;
            return;
        }

        float height = Math.Max(-body.Com.Y, 20f);
        float omega = MathF.Sqrt(Ragdoll.Gravity / height);
        float xi = body.Com.X + body.ComVel.X / omega;
        if (xi >= body.SupportMin && xi <= body.SupportMax) _stepArmed = true;

        if (_swingFoot < 0 && _stepArmed &&
            (xi < body.SupportMin || xi > body.SupportMax))
        {
            float direction = MathF.Sign(body.ComVel.X);
            if (direction == 0f) direction = xi > body.SupportMax ? 1f : -1f;
            int first = direction > 0f ? body.FootFar : body.FootNear;
            int second = direction > 0f ? body.FootNear : body.FootFar;
            _swingFoot = body.Bodies[first].GlobalPosition.X <= body.Bodies[second].GlobalPosition.X ? first : second;
            if (direction < 0f)
                _swingFoot = body.Bodies[first].GlobalPosition.X >= body.Bodies[second].GlobalPosition.X ? first : second;

            _swingElapsed = 0f;
            var foot = body.Bodies[_swingFoot];
            _swingStartX = foot.GlobalPosition.X;
            _swingStartY = foot.GlobalPosition.Y;
            _swingTargetX = xi + 0.1f * direction * Ragdoll.RefHeight;
            _stepArmed = false;
            CapturePointSteps++;
        }

        if (_swingFoot < 0) return;

        _swingElapsed += dt;
        float p = Math.Clamp(_swingElapsed / SwingDuration, 0f, 1f);
        float smooth = p * p * (3f - 2f * p);
        float targetY = _swingStartY - SwingHeight * MathF.Sin(MathF.PI * p);
        SetSwingTargets(body, b, _swingFoot, Mathf.Lerp(_swingStartX, _swingTargetX, smooth), targetY, p);
        if (p >= 1f) _swingFoot = -1;
    }

The protocol gate is Recover probability >= 0.5 and support present. The
capture point is COM.X + COM.Vel.X / sqrt(Gravity / height); the selected
foot is swung to capture point + 0.1 * direction * RefHeight. The transfer
uses elapsed time / SwingDuration (0..1), smoothstep horizontal motion, and
a sinusoidal vertical arc. SetSwingTargets marks the swing leg's hip, knee,
and ankle swinging while progress < 1. Previously there was only this timed
transfer phase; it had no separate landing phase or contact-driven ramp.

b) Before Fix015, CapturePointStepping was only the public bool defaulting
to true; no keyboard or diagnostic flag toggled it. Fix015 adds Main's C
key for the motor chip in the MOTOR slot; it toggles MotorRom's
CapturePointStepping or NeuralMotorChip's BaseStepping and reports
"CP STEP ON/OFF".

c) The user-configurable minimum exam level is:

    RecoverTask.MinExamLevel
    Dream._minLevelOverride
    --min-level 0..1

Dream applies the configured floor to both Recover directions and prevents
curriculum reductions below it.

1. NeuralMotorChip

Before: the embedded MotorRom always ran with its own default stepping flag.
After: added BaseStepping = true and assign it to `_base.CapturePointStepping`
immediately before `_base.Tick`. NeuralMotorChip does not clear
Brain.SwingingJoints after that tick. It reads the ROM swing flags to choose
the smaller residual target scale and to preserve ROM stiffness during swing.

2. Residual groups and smoothing

Added public scales ResTargetUpper = 0.5, ResTargetLeg = 0.2,
ResTargetSwing = 0.1, ResTau = 0.06, and existing ResStiff = 0.4. Reset
builds the leg classification once using hip*, knee*, ankle* joint names and
clears preallocated _rt/_rs filters. In Tick, tanh target/stiff outputs are
filtered by min(1, dt/ResTau). Target residual scale is selected by
SwingingJoints first, then leg vs upper. Swing stiffness remains the base ROM
stiffness. No arrays are allocated by the added per-joint Tick logic.

3. Timed landing phase

The existing step already has a normalized timed phase p = elapsed / 0.45 s,
so no extra `_air` phase was needed. Added:

    LandPhase = 0.35
    LandStiff = 0.25
    LandRamp = 0.12 seconds
    LandKnee = 0.25 radians

During the final 35% of transfer, hip/knee stiffness is set to LandStiff,
knee bend is clamped to at least LandKnee, and the ankle target tracks the
negative world shin rotation, making the foot approximately horizontal.
Ground contact during this phase or completion of the timed arc enters a
landing state. Until contact, the landing pose is held at LandStiff. After
contact, hip/knee stiffness ramps from LandStiff to the current base ROM
stiffness over LandRamp. SwingingJoints remains set through the landing
hold/ramp so reflex and NN residuals do not override the scripted leg.

4. Knee reflex coordination

Before: the air-time knee reflex always applied during its timer window.
After: it first maps the ankle to its knee and only applies when the knee is
valid and that knee is not marked in Brain.SwingingJoints.

5. Landing impact

RecoverTask now has ImpactCost = 2 and ImpactFree = 60 px/s. RecoverEpisode
detects only false-to-true foot-ground transitions after the first push,
measures downward velocity (Y positive), computes

    ImpactCost * (max(0, vy - ImpactFree) / 100)^2

and subtracts it from reward. The new Impact penalty term is reset each
tick, included in the episode score, and cleared on fall. Exam reports
include `удар=<maximum landing speed in px/s>`. Ground-contact state is
sampled at the initial push to avoid counting an already-grounded foot as a
new landing.

6. Manual verification

Main's C key checks the MOTOR slot regardless of current selection:
MotorRom toggles CapturePointStepping; NeuralMotorChip toggles BaseStepping.
Other chip types produce a short explanatory message. C was not previously
used in Main.
