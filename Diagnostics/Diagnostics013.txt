    (impact is now Ache, not Acute; limit signal unchanged)
  - Hose tear: was "ar += HoseJolt;" → now "xr += HoseJolt;"
    (first hose tear is now Acute, not Ache)
  - Broken joint past limit: new else-branch on the "if (!broken)" block:
      else if (edge < 0f)
      {
          float over = -edge;
          float p = OverAche * over;
          ar += p; lr += p; Side[j] = side;
          float move = Math.Min(1f, MathF.Abs(b.AngVel[j]) / OverVel);
          xr += OverAcute * over * move;
      }
  - Class comment updated to match new level assignments.
