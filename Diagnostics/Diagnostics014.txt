Fix019 — Diagnostics report
===========================

## 1. Gen timing and ETA (Dream/Dream.cs)

New fields added:
  ulong _genT0          — wall-clock start of current generation (Time.GetTicksMsec)
  ulong _dreamT0        — wall-clock start of entire dream
  float[] _recentGenSec — ring buffer, last 5 generation durations (seconds)
  int _recentIdx        — ring buffer write head
  int _recentFilled     — how many entries are valid
  float _bestExam       — best exam score seen across all gens
  int _bestExamGen      — generation at which best exam was achieved

Changes in _Ready():
  _dreamT0 = _genT0 = Time.GetTicksMsec() called just before StartGeneration().

Changes in EndGeneration():
  - Measures elapsed ms since _genT0, converts to float seconds, resets _genT0 = now.
  - Updates ring buffer (_recentGenSec / _recentIdx / _recentFilled).
  - Computes avgSec from filled entries; etaStr = "| Xs/gen ETA hh:mm" when MaxGenerations>0.
  - Tracks _bestExam / _bestExamGen.
  - Appends etaStr to DreamLog.Line gen output.
  - On quit condition: emits "dream END gens=N total=hh:mm:ss best exam=X.XXX (gen K)"
    before GetTree().Quit().

  - pause at end so window stays open.

- ETA shows "00:00" for 3-gen trial because remaining=0 after last gen completes.
  For 200-gen run it will show real ETA (e.g. "00:15" for ~15 minutes remaining).
