## 1. ArbiterRom — по спецификации (якорей нет, поэтому показать до/после)
a) Добавить `public void Force(int protocol)`: немедленно перейти в `protocol` тем же путём, что и обычный переход (со смешиванием), сбросить таймер выхода.
b) Переход RECOVER→STAND разрешать ТОЛЬКО если непрерывно в течение `ExitDwell = 0.3f` с одновременно:
   - выполнено существующее условие выхода по ξ/Margin;
   - `Bal.GroundN > 0.5 && Bal.GroundF > 0.5`;
   - расстояние по X между `Bodies[FootNear]` и `Bodies[FootFar]` ≤ `ExitSpread = 20f` px;
   - |скорость ЦМ по X| ≤ эквивалент 15 px/s (`ExitVel`, пересчитать в единицы Bal.ComVx).
   Таймер копить по dt арбитра, сбрасывать при нарушении любого условия.
c) Остальные переходы (в GETUP, вход в RECOVER) не трогать.
Если в ArbiterRom нет явного перехода RECOVER→STAND (например, только непрерывное смешивание p) — СТОП, процитировать код.
