## 2. EDIT `RomChips.cs` (ReflexRom.Tick) — голеностоп
Якорь (весь блок, внутри `if (bl[Bal.Lying] < 0.5f)`):
```

                {
                    float off = Scale * (AnkleGain * bl[Bal.ComX] + AnkleDamp * bl[Bal.ComVx]);
                    off = Math.Clamp(off, -AnkleMax, AnkleMax);
                    foreach (int a in body.Ankles)
                    {
                        if (DoNotTouchSwingingLeg && b.SwingingJoints[a]) continue;
                        if (!body.Grounded[FootOf(body, a)]) continue;
                        b.ReflexTarget[a] += off;
                    }
                }
```
Заменить на:
```
                int nj = b.ReflexTarget.Length;
                if (_ank == null || _ank.Length != nj) { _ank = new float[nj]; _air = new float[nj]; }
                float off = 0f;
                if (bl[Bal.Support] > 0.5f)
                    off = Math.Clamp(Scale * (AnkleGain * bl[Bal.ComX] + AnkleDamp * bl[Bal.ComVx]), -AnkleMax, AnkleMax);
                float pr = Math.Clamp(b.P[Protocol.Recover], 0f, 1f);
                foreach (int a in body.Ankles)
                {
                    int ft = FootOf(body, a);
                    bool on = body.Grounded[ft] && bl[Bal.Support] > 0.5f
                              && !(DoNotTouchSwingingLeg && b.SwingingJoints[a]);
                    float k = Math.Min(1f, dt / (on ? AnkleEngageTau : AnkleReleaseTau));
                    _ank[a] += ((on ? off : 0f) - _ank[a]) * k;
                    b.ReflexTarget[a] += _ank[a];

                    // перенос: колено сгибается в первые SwingTime с после отрыва стопы
                    _air[a] = body.Grounded[ft] ? 0f : _air[a] + dt;
                    if (SwingKnee > 0f && _air[a] > 0f && _air[a] < SwingTime)
                        b.ReflexTarget[KneeOf(body, a)] += SwingKnee * pr * MathF.Sin(MathF.PI * _air[a] / SwingTime);
                }
```
Добавить `static int KneeOf(Ragdoll body, int ankleJoint)`: имя сустава ankle_X → индекс сустава knee_X в Def.Joints, кэш в `_kneeOf`. Если knee_X не найден — СТОП.
