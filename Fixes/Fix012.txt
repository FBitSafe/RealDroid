# Дополнение к Fix011 (выполнить Fix011 целиком с этими поправками)
Режим: Agent. Якорь не найден дословно — СТОП и отчёт.

## Шаг 1 — новый якорь (заменяет якорь из Fix011)
Якорь:
```
                    float tau = on ? AnkleEngageTau : AnkleReleaseTau;
                    float k = Math.Min(1f, dt / Math.Max(tau, 1e-6f));
                    _ank[a] += ((on ? off : 0f) - _ank[a]) * k;
                    b.ReflexTarget[a] += _ank[a];
```
Заменить на:
```
                    float tau = on ? AnkleEngageTau : AnkleReleaseTau;
                    float k = Math.Min(1f, dt / Math.Max(tau, 1e-6f));
                    _ank[a] += ((on ? 1f : 0f) - _ank[a]) * k;      // _ank — вес включения 0..1
                    b.ReflexTarget[a] += _ank[a] * off;             // сигнал баланса без задержки
```

## Шаг 7c — заменить условие порога
Вместо фиксированного `ReplayFloor = 0.6f`:
- Порог действует ТОЛЬКО когда основная задача сна — `RecoverTask`.
- Запомнить replay первого поколения, где он измерен: `_replayStart`.
- Эффективный порог: `floor = Math.Min(ReplayFloor, _replayStart - 0.05f)`, где `ReplayFloor = 0.6f`.
  (Если STAND уже испорчен, порог не даст испортить его ещё сильнее, но и не заблокирует сохранение навсегда.)
- ★ ставить, только если replay текущего поколения ≥ floor. Если replay в этом поколении не измерялся — не блокировать.
- Печатать `floor` один раз при старте сна: `DreamLog.Line($"replay floor {floor:0.00}")`.

## Общее правило для этого задания
Если якорь отличается только переименованием локальной переменной или вынесением выражения в переменную при той же логике — НЕ останавливаться: показать в отчёте «ожидалось / найдено / заменено» и продолжить. В остальных случаях — СТОП.
