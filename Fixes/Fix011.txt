## 1. EDIT `RomChips.cs` — фильтровать ВКЛЮЧЕНИЕ рефлекса, а не сигнал (ошибка Fix010: фазовая задержка → раскачка)
Якорь:
```
                    float k = Math.Min(1f, dt / (on ? AnkleEngageTau : AnkleReleaseTau));
                    _ank[a] += ((on ? off : 0f) - _ank[a]) * k;
                    b.ReflexTarget[a] += _ank[a];
```
Заменить на:
```
                    float k = Math.Min(1f, dt / (on ? AnkleEngageTau : AnkleReleaseTau));
                    _ank[a] += ((on ? 1f : 0f) - _ank[a]) * k;      // _ank — вес включения 0..1
                    b.ReflexTarget[a] += _ank[a] * off;             // сам сигнал баланса без задержки
```

## 6. EDIT `DreamTasks.cs` — штраф за застывший шпагат (только когда опасность прошла)

```

```
Заменить на:
```
                _rewards[2].Value = T.PoseWeight * pw * pose;
                rew += _rewards[2].Value;

                // спокойно, ξ внутри опоры, а ноги всё ещё врозь — пора приставлять ногу
                float calm = pw * Math.Clamp(1f - MathF.Abs(comVx) / T.CalmVel, 0f, 1f) * (outside <= 0f ? 1f : 0f);
```
