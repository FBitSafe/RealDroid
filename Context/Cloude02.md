## 2. Физика и тело

- Гироскоп — аугментация `Ragdoll.GyroOn`, по умолчанию true, клавиша G.

## 3. Мозг
Шина с каналами `float[]`. Такт: Vest → Arb → Motor → Reflex → Compose → Firmware.

**`Bal.*`** (единицы /H): PelvisTilt 0, PelvisW 1, ChestTilt 2, ChestW 3, ComX 4, ComVx 5, Xi 6, HalfWidth 7, Margin 8, GroundN 9, GroundF 10, Support 11, Lying 12, ComH 13, Size 14. Опора считается по стопам, которые касаются пола (`SupportMin/Max`).

| Слот | Гц | Чипы |
|---|---|---|
| ПРОШИВКА | 240 | FW 1.1, FW OC! |
| ВЕСТИБУЛЯР | 120 | VEST ROM, VEST б/у |
| РЕФЛЕКСЫ | 120 | REFLEX ROM 1.2, x2.5 |
| АРБИТР | 10 | ARB ROM, ARB LOCK STAND |
| МОТОРНАЯ КОРА | 30 | MOTOR ROM, MOTOR NN (файл), BLANK |

**Compose:** target = мотор + рефлекс; stiff = max(мотор·(1−inhibit), рефлекс). Если `Brain.GetupEnabled == false` (по умолчанию) и P[Getup] > 0, мотор становится вялым (`LimpStiff` 0.05) и держит текущие углы. **GETUP выключен**, потому что вызывал конвульсии.

**ArbiterRom:** переход STAND→RECOVER при Margin < 0. **RECOVER→STAND** разрешён, только если 0.3 с подряд выполняется всё сразу: Margin > ExitMargin, обе стопы на полу, расстояние между стопами ≤ `ExitSpread` 20 px, $|ComVx|$ ≤ 0.15. Метод `Force(protocol)` переключает протокол принудительно.

**ReflexRom:**
- Голеностоп работает только на стопе, которая стоит на полу. Плавно включается **вес** рефлекса (`_ank` 0..1, Engage 0.12 с / Release 0.04 с), сам сигнал баланса не задерживается.
- Рефлекс колена в переносе: `SwingKnee` 0.5, 0.3 с, масштабируется по P[Recover], не действует на суставы из `SwingingJoints`.
- `GuardRecoverRelief` 0.7 ослабляет оцепенение в RECOVER.
- Флаг `DoNotTouchSwingingLeg`.

**NeuralMotorChip `motor_v4` (residual:rom):**
- Сначала тикает встроенный `MotorRom` (`BaseStepping` → `CapturePointStepping`), потом NN.
- Цель сустава: $target=clamp(base+s\cdot\overline{\tanh o})$. Масштаб $s$: Upper 0.5, Leg 0.2, Swing 0.1. Поправки сглажены (`ResTau` 0.06).
- Жёсткость: $stiff=base+0.4\cdot\overline{\tanh o}$; у маховых суставов остаётся как в ROM.
- Выходной слой (W3, b3, Op) при создании обнулён, поэтому **свежий чип = ROM** (проверено пробой).
- Чипы v3 несовместимы: Main пишет об этом и ставит MOTOR ROM.

**MotorRom:** позы протоколов смешиваются по P. Скриптовый шаг `ApplyCapturePointStep` включается при P[Recover] ≥ 0.5 и расчёте $\xi=x+\dot x/\sqrt{g/h}$. Цель стопы: $\xi+0.1H\cdot dir$, `SwingDuration` 0.45, высота 18 px. Фаза посадки из Fix015: LandPhase 0.35, LandStiff 0.25, LandRamp 0.12, LandKnee 0.25.

## 4. Сон (Dream / DreamJob / DreamTasks / EsOptimizer)
- OpenAI-ES, антитетические пары с **общим seed** (проверено), ранги, Adam.
- Маска: свой сектор 1, общие веса $1/(1+\text{SharedDamp}\cdot\sum\text{зрелости других})$, `SharedDamp` = 4.
- `ReplayShare` 0.5: столько пар повторяют зрелые сектора.
- Для RECOVER ★ (сохранение лучшего) ставится, только если replay ≥ $\min(0.6, replay_{start}-0.05)$.
- `GyroOffShare` 0.3: доля тренировок с выключенным гироскопом (одинаково внутри пары). На экзаменах гироскоп всегда включён.
- Лог пишется через `DreamLog.Line` в `user://dream_log.txt`.

**Аргументы запуска:**
- `--headless --fixed-fps 30 res://Dream.tscn -- --gens N --sector X --fresh --pristine --chip path --shared x --level x --min-level x`
- Проба выносливости: `--probe 60 --motor rom|nn --wear off|live --gyro on|off`
- Тест ROM-шага: `--motor-rom-step-test`, в Fix016 к нему добавлен `--levels 0.3,0.5,0.7`.

**StandTask:** 6 с, ветер, 2 экзамена (ветер и штиль).

**RecoverTask (текущее):**
- 7.5 с, в каждой тренировке два толчка в разные стороны с интервалом 3 с.
- Уровни раздельные: `LevelFwd` для толчка в спину (+x, это тяжёлое направление) и `LevelBack` для толчка в грудь. Плюс `MinExamLevel`.
- 4 экзамена: 0 и 2 в спину, 1 и 3 в грудь; у 2 и 3 есть предварительный толчок −0.2. **На экзамене RECOVER включается принудительно**, на тренировке в 80% эпизодов.
- **Экзамен сдан** = не упала **и** в конце в STAND (`IExamVerdict`).
- Награда:
  - штраф за выход $\xi$ за промежуток между стопами (`FootMarginCost` 3);
  - поза включается плавно через 1.5 с после толчка;
  - `ReturnBonus` только в контрольных окнах (0.75 с перед вторым толчком и в конце) и только если STAND, ноги вместе, $\xi$ внутри опоры, скорость мала;
  - `StanceCost` 1.5 за широкую стойку в спокойном состоянии;
  - `ImpactCost` 2 за удар стопы со скоростью больше 60 px/s.
- Строка экзамена: `толчок, исход, t, recover=, шаг=, acute=(сустав@время), поза, дребезг, колено, удар`.
- **Строки `exam` под `gen N` относятся к поколению N+1.**

**Клавиши Main:** 1–5 слот, Space вынуть/вставить, Tab вариант, ЛКМ тащить, Q/E толчок, G гироскоп, D схема, K режим износа, J состарить, H ремонт, R заново, T сон STAND, Y сон RECOVER, **L** GETUP вкл/выкл, **C** CP-шаг вкл/выкл.

## 5. Ошибки, найденные за проект (не повторять)
1. Пределы `PinJoint2D` не используются, упоры сделаны своими силами. Жёсткость упора не больше $0.3I/dt^2$, демпфирование не больше $0.6I/dt$.
2. $I_{eff}$ для SPD считается только по двум соседним телам.
3. Угол сустава непрерывный, без wrap.
4. Если учить без эталона и с толчком в каждом эпизоде, получается «группировка». Протокол учится только в своей ситуации.
5. **Экзамен «не упала» можно обмануть:** сеть застыла в шпагате с руками в стороны («пешеход») и держала 100%. Экзамен должен проверять, что задача **выполнена**.
6. **Бонус за каждый тик в STAND наказывает сам сектор RECOVER.** Награждать нужно итог в окне, а не состояние.
7. **Смешение направлений толчка:** общий уровень упирался в слабое направление. Нужны раздельные уровни.
8. **Детерминизм:** одинаковые экзамены дают одинаковый результат. Нужно разнообразие (предварительный толчок).
9. **Фильтровать сигнал обратной связи нельзя:** фазовая задержка вызывает раскачку. Фильтровать можно вес включения.
10. **Гироскоп всегда включён во сне:** NN научилась на него опираться (stiff 0.34 против 0.75 у ROM, выгнутый позвоночник). Без гироскопа она падала за 0.6 с.
11. **NN без базы портила STAND через общие веса** (replay падал ниже 0). Остаточная схема поверх ROM это вылечила: поза 0.98–0.99.
12. **Учить NN поверх неработающего скрипта бессмысленно.** Сначала headless-тест базы.
13. Посадка стопы без таймаута: нога висела до конца эпизода. Обратная кинематика при упоре бедра компенсировала коленом до 2.4 рад, и нога складывалась как у фламинго.
14. Знаки и единицы (ComVx в px/s/H, сгибание колена +, Y вниз) **просить агента проверять**, не предполагать.
